Start with the essentials, then use the topics below as a compact map of the language and runtime.

Installation

Download a release or build Ibex from source. The installation guide includes both paths.

Quickstart

Read a table, transform it, and print a result in the first pipeline guide.

REPL

Use the REPL to inspect tables, run expressions, and load scripts. See the REPL walkthrough.

Language

Pipelines

Tables flow through bracketed clauses such as filter, select, and update.

Expressions

Expressions combine columns, literals, operators, and calls. They are checked before execution.

Types

Ibex has static scalar, series, table, and time-frame types. See the language reference for details.

Functions

Use built-ins for common data work and typed fn declarations for reusable code. Browse the function reference.

Control flow

Use expressions and functions to define transformations; pipelines keep data work declarative.

Data

Reading & writing

CSV, JSON, Parquet, and other data sources are provided through plugins. Read the I/O guide.

Joins

Combine tables by matching key columns; choose the join that preserves the rows you need.

Aggregation

Use by with select or update to reduce or transform groups.

Window operations

TimeFrames support ordered, rolling operations. See the OHLC window example.

Integration

Python

Use Ibex from notebook workflows while keeping tables and scalar bindings typed. Details live in the integration reference.

R

The R package offers a lazy dplyr backend with an explicit fallback boundary.

C++ / native compilation

Compile an Ibex program to C++23 for native deployment, or connect a custom source through an extern function.

Syntax

CLI

Run scripts or start the interactive REPL with the ibex executable.

Configuration

Configure plugin paths and runtime options when starting Ibex.
