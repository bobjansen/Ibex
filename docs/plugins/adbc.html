ADBC

Query databases through Arrow Database Connectivity, including SQLite and other installed drivers.

One-shot query

adbc::read(driver, uri, sql, options = "") -> DataFrame opens a connection, runs one query, and closes it.

Reusable connection

connect opens an adbc::Connection; use query, execute, write, tables, table_schema, begin, commit, rollback, and close against it. Queries may bind a DataFrame of parameters by column position. Writes support create, append, replace, and create_append modes. Options are semicolon or newline separated key=value entries.

import "adbc"; let db = adbc::connect("/path/to/libadbc_driver_sqlite.so", "data.sqlite"); let rows = adbc::query(db, "select * from trades"); adbc::close(db);
