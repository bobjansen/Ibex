Command-line arguments

Declare a command-line interface and receive parsed values as a table.

args::parse

args::parse(spec: String, argv: String = "") -> DataFrame

The specification uses one declaration per line or semicolon: name (aliases) : type [arity] [= default] # help. Supported types are int, int64, float, float64, bool, string, date, and timestamp. Arity can be a single value (the default), flag, +, *, positional, positional+, or positional*. A trailing ? makes an argument optional.

The result has kind, name, index, and value columns. Values are strings (flags use true/false); cast them to the desired type. Missing optional arguments produce no row. Without explicit argv, input comes from IBEX_ARGS (one argument per line).

import "args"; let parsed = args::parse("threads (t) : int = 4; input : positional+");
