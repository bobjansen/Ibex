CSV

Read delimited text into typed tables and write DataFrames back to CSV.

Functions

csv::read(path, nulls = "", delimiter = ",", has_header = true, schema = "") -> DataFrame

Reads a headered CSV by default and infers integer, float, and string/categorical columns. Use nulls for comma-separated null tokens (<empty> includes empty fields), delimiter for another separator, and has_header = false for generated col1, col2 names. A schema hint avoids inference when types are known.

csv::write(df, path) -> Int writes a header and rows, returning the row count.

import "csv"; let trades = csv::read("trades.csv"); let written = csv::write(trades, "copy.csv");
