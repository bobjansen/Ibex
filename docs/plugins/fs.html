Filesystem

Enumerate files as a DataFrame, then use ordinary Ibex clauses and row-wise map to build file jobs.

fs::list

fs::list(dir: String, pattern: String = "*", recursive: Bool = false) -> DataFrame

Returns one row per matching directory entry, sorted by path. The fixed columns are path, name, stem, ext, size_bytes, and is_dir. stem is the filename without its final extension; ext is that extension. The pattern is a shell glob (*, ?, [set]) matched against the entry name. Set recursive to true to include descendants.

import "fs"; let files = fs::list("data/csv", "*.csv"); files[select { path, stem, ext, size_bytes, is_dir }];

Use entries as a batch job

Inside map, each input row exposes entry columns as scalar values. Here stem keeps each output name aligned with its source.

import "csv"; import "fs"; import "parquet"; fs::list("data/csv", "*.csv")[map { source = path, target = `data/parquet/${stem}.parquet`, rows = parquet::write(csv::read(path), `data/parquet/${stem}.parquet`) }];
