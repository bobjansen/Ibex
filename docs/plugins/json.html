JSON

Read and write JSON files as Ibex DataFrames.

Functions

json::read(path: String) -> DataFrame reads a JSON file using the formats supported by the bundled plugin.

json::write(df: DataFrame, path: String) -> Int writes a DataFrame and returns the number of rows written.

import "json"; let events = json::read("events.json"); json::write(events, "events-copy.json");
