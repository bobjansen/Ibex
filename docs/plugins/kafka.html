Kafka

Consume JSON or Schema Registry framed Avro messages and publish DataFrame rows.

Functions

kafka::recv(brokers, topic, group, schema, options = "") -> DataFrame polls for one JSON message and converts it to a typed one-row table.

kafka::recv_avro(brokers, topic, group, schema, registry_url, options = "") -> DataFrame consumes one flat Avro record using its Schema Registry writer schema.

kafka::send(df, brokers, topic, options = "") -> Int publishes each DataFrame row as a JSON message. The schema format is comma-separated name:type, such as ts:timestamp,symbol:str,price:f64. Options are semicolon-separated key/value settings; receive poll timeout and producer flush timeout can be set there.

import "kafka"; let tick = kafka::recv("localhost:19092", "ticks", "demo", "symbol:str,price:f64");
