Parquet

Store typed tables in compact columnar files for efficient reloads and scans.

Functions

parquet::read(path: String) -> DataFrame reads supported Parquet types. The bundled backend also accepts HTTP(S) URLs and S3 URIs.

parquet::write(df: DataFrame, path: String) -> Int writes a Parquet file and returns the number of rows written.

import "parquet"; let prices = parquet::read("prices.parquet"); parquet::write(prices, "prices-copy.parquet");

See remote reads and more examples in the complete I/O guide.
