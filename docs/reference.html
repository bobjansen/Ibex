At a glance

The shape of an Ibex program

Programs bind immutable values, then transform tables with named clauses. Clauses run from left to right inside a table expression.

import "csv";
let prices = read_csv("prices.csv");

let summary = prices[
    filter volume > 0,
    select { average = mean(price), traded = sum(volume) },
    by symbol,
    order { traded desc }
];

Language

Core forms and table operations

let name = valueBind an immutable scalar, series, table, or function result.
fn name(args) -> Type { ... }Declare a typed reusable function.
import "plugin"Load a bundled I/O plugin.
extern fn ... from "header.hpp"Declare a native function or source.
Table { field = values }Create a table from column expressions or literals.
filter predicateKeep rows for which the predicate is true.
select { fields }Project fields, create computed fields, or aggregate with by.
update { fields }Add or replace fields while preserving the remaining columns.
by keyGroup a select or update.
order { keys }Sort rows using ascending or descending keys.
rename, distinct, head, tailRename, deduplicate, or limit rows.

See the transformation tutorial for first use, and the language specification for grammar and exact rules.
